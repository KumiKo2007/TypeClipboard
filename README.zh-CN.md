# TypeClipboard

[English README](README.md)

TypeClipboard 是一款 SwiftUI macOS 工具，将可编辑缓冲区中的文本模拟为键盘输入。它适合普通粘贴不可用的远程会话和网页代码编辑器。应用只负责发送按键，无法验证目标编辑器最终保存的内容。

## 功能

- 从剪贴板捕获纯文本，并在输入前编辑缓冲区
- 设置倒计时与字符间隔
- 将原文中的换行发送为 Enter 或 Shift+Enter 按键；Tab 发送为 Tab 按键
- 手动选择“学习通”或“通用”配置，并分别记住换行与括号配对设置
- “自动跟随系统 / English / 简体中文”界面语言
- 倒计时和输入期间，按新的实体键盘按键即可取消；也可点击“取消输入”
- 可选自动捕获剪贴板变化，默认关闭
- 可选在输入完毕后额外按 Return，默认关闭

## 获取与权限

可从项目的 [Releases 页面](https://github.com/ArbenP/TypeClipboard/releases)下载 `.app`。应用需要 macOS 13 或更高版本。

首次启动时，在应用提示中点击“打开设置”，于“隐私与安全性 ▸ 辅助功能”启用 TypeClipboard，然后重新启动。若提示无法监听键盘，还需在“隐私与安全性 ▸ 输入监控”中启用 TypeClipboard。取消监听无法启动时，应用不会开始模拟输入。

## 使用方法

1. 点击“捕获剪贴板”（⇧⌘V），或直接编辑缓冲区。
2. 手动选择“学习通”或“通用”配置，并为目标编辑器选择 Enter 或 Shift+Enter 换行。应用不会读取浏览器网址或自动识别网页。
   如果目标编辑器输入 `{` 后立即自动补出 `}`，开启“移除编辑器自动补出的右花括号”。学习通配置默认开启，通用配置默认关闭。请从空白编辑器开始输入。开启时应用会在每个 `{` 后发送一次前向删除，以清除自动补出的 `}`；若编辑器不会立即自动配对，请关闭此项，尤其在光标右侧已有内容时。
3. 点击“开始输入”，在倒计时内将焦点放到目标输入框。按需调整倒计时和字符间隔。
4. 需要取消时，按实体键盘上的任意新按键（包括单独的修饰键），或点击“取消输入”。用于取消的按键会被拦截，不写入目标内容。
5. 输入完成后，请在目标网页核对代码，再决定是否保存或提交。

原文自带的末尾换行会照常发送。“输入后额外按 Return”是独立选项，默认关闭。某些网页编辑器会自动缩进、将 Tab 用于切换焦点，或改写合成按键；此时可以更换换行模式、检查编辑器设置，但应用不会把 Tab 悄悄改成空格，也不会声称已验证网页中的内容。

## 常见问题

- **没有输入**：检查辅助功能权限；安全输入框可能拒绝合成按键。
- **提示无法监听键盘**：启用输入监控权限后重试。
- **换行或缩进不一致**：尝试另一种换行模式，并检查目标编辑器的自动缩进设置。
- **多出 `}`**：确认编辑器是否在输入 `{` 后立即补出 `}`；只有这种情况才开启括号补偿。如果编辑器仅在按 Enter 后自动补 `}`，请先在目标编辑器设置中关闭自动补全括号；此选项只处理立即出现的配对括号。
- **缓冲区被更新**：保持自动捕获关闭，或在需要时手动重新捕获。
- **速度不合适**：调整字符间隔（0–250 毫秒）和倒计时。
